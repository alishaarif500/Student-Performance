# 🎓 Student Performance Prediction

An end-to-end Machine Learning project designed to predict students' final academic grades (G3) using demographic, social, behavioral, and academic performance indicators.

The project uses the **UCI Student Performance Dataset** and applies Python-based data science and machine learning techniques to analyze student performance patterns and estimate academic outcomes.

### Key Features
- Automated dataset downloading and loading.
- Exploratory Data Analysis (EDA) and data visualization.
- Data preprocessing, categorical encoding, and feature scaling.
- Machine Learning models: Linear Regression, Ridge Regression, Random Forest, Gradient Boosting, and Support Vector Regression (SVR).
- Model evaluation using MAE, MSE, RMSE, and R² Score.
- Hyperparameter optimization using GridSearchCV.
- Feature importance analysis and model explainability.
- Interactive Streamlit-based prediction interface.
- Responsible AI considerations and bias awareness.

### Technologies Used
Python | Pandas | NumPy | Matplotlib | Seaborn | Scikit-learn | Jupyter Notebook | Google Colab | Streamlit

### Project Objective
To explore the factors associated with student academic performance and develop a predictive system that can help identify students who may benefit from additional academic support.

**Note:** Predictions are intended for educational support and early intervention, not for penalizing or labeling students.
